# Journal App

A full-stack journal application that allows users to securely create and manage personal journal entries with authentication and protected access.

## Features

- User registration and login
- JWT-based authentication
- Protected routes
- Create journal entries
- Update journal entries
- Delete journal entries
- View personal journal dashboard
- Secure backend APIs

## Tech Stack

### Frontend
- React.js
- React Router
- Axios
- CSS

### Backend
- Spring Boot
- Spring Security
- JWT Authentication
- Maven

### Database
- MongoDB
